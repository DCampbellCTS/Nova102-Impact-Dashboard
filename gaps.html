How the check works

Due soon

The field needs it within two weeks and the model does not have it. Raise the same day.

Ask now

Nobody has confirmed whose scope it is. Ask anyway, so the out-of-scope items are known early.

Stalled at BES

It is in BES's scope but held or not started. Ask what releases it and when.

Watch

Probably fine, or already in the RFI channel. Re-checked each week.

1 · Coverage

Design sheet vs model, per area

For each location and system with a design plan sheet, count elements in both models and flag anything empty.

2 · Counts

Drawing tags vs model families

Count device tags on the design sheet and compare with the model. Floor boxes today; other device types as they come up.

3 · Need date

Rank by when the field needs it

Join each gap to ARCO's lookahead (slab, foundation, install dates) and BES's priority list, so the nearest deadline is at the top.

4 · Follow-through

Answered RFIs the model never absorbed

For answered RFIs tied to an area and system, check whether the model changed there afterwards. Flag after 10 working days with no change.

5 · Field voice

What Triad is already saying

Search RFI and submittal text for phrases like "model only showing" and "plan vs model". A hit means someone has already noticed.

Limits

The design baseline is the IFP 06-29 set until the IFC electrical drawings are on ACC (Q7).

The check only sees what is drawn. An expectation that exists only in conversation won't show up. The weekly RFI and field-voice sweeps catch some of those.

BES's priority list is the 09-25 copy (v1.3). A newer list may already show some of these holds released.

Location comes from geometry. Work-package tags and FROM/TO are checked before anything is attributed to Admin, because Admin's grid block also carries COLO1 and Mech Yard work.
